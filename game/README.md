# エネルギーシティ（試作 v6）

町長になって、3D の町に電気をとどけるゲームです。
7人の発電キャラを組み合わせて、夜も、くもりの日も、風のない日も停電しない町をつくります。

- インストール不要。`index.html` をブラウザ（Chrome / Edge 推奨）で開くだけで動きます（インターネット接続も不要）
- 🎓 チュートリアル 約3分 → 本編 約8分（2026〜2050年、1日＝1年。×2・×3の早送りあり）
- 見た目は「仮想プログラミング」と同じ作り（Three.js のおもちゃブロック、チャッピー）
- BGM・効果音・環境音は Web Audio でその場で鳴らしています（音声ファイルなし・オリジナル曲）

## おまけ「町の地図で 2050年へ」のあそびかた

1. 下の **カード** をえらび、光るマスに建てる（置ける場所は電源ごとにちがう。黄色のマスは町の人の声が出る場所）。カードの ⏳ は使えるまでの年数

3. **⏩ 3年すすめる** で、完成・引退が起こり、その年の町を4つの日でためす（停電した日は1日のグラフが出る）
4. 2050年まで8回くりかえし、うつりかわりの表を見てふりかえる
5. ⚛️原子力は新しく建てられない（年数の公式な資料がないため）。🔥火力は建てられるが、完成まで約10年かかり、40年残る

## 考える力を育てる仕掛け（批判的思考）

- **🗣️ 町の人・国民の声**：第4部とおまけでは、ふやした電源・建てる場所に応じて、立地地域・温泉・漁師・ダムの村・火力の町などの心配が出る。数字がよくなっても、こまる人がいる
- **⏳ 建てるのに時間がかかる・👴 何十年も残る**（おまけ）：完成まで♨️約14年・🔥約10年。引退の波を見こして早めに建てはじめないと、停電する年が出る
- **⚡ 規模がわかる**：シナリオの選択肢・表・第3部の設計には「☀️昼 ⚡25／🌙夜 ⚡0」のように、グラフの「使う量」と同じものさしで出せる量を表示（太陽光7つと火力1つの大きさのちがい）
- **🤔 ゲームと ほんとうの ちがい**：このゲームは「モデル」。季節・送電線・世界のCO₂・数字の単純化・原子力の課題・蓄電池の課題・ほかの電源など、現実とのちがいを考える
- **⚖️ クリア＝かんぺき ではない**：シナリオの各話では、クリアしても「表を読もう」に答えないと次へ進めない。自分の選択が負けている ものさしと、ほかの選択の弱点を表から見つける。大作戦3Dでも、ものさしを1つずつ「よく／おなじ／わるく」と判定し（ぜんぶ答えるまで次へ進めない）、それから答えを見る
- **🔋 蓄電池だけが答えではない**：あまった電気は「ためる・時間をずらす・となりへ送る・少しすてる」のどれにも弱点がある（グラフ探偵の解説カード）。第3部の「🧯電池の点検」の日は🔋の約35%が止まり（韓国 2019年の例）、電池だけにたよる設計は停電する。電池の材料の輸入・火事への備え・寿命は、ずかん（ゲームとほんとうのちがい）と大臣クイズで扱う
- **⬛ 停電の色**：グラフの停電は黒（まっくら）。🔥火力の赤と区別できる
- **🗾 割合だけでは決まらない**：大作戦3Dでは、1年の平均で足りていても、雨の夜や猛暑の夕方に足りなければ停電する。だから「4つの日 停電なし」を目標に入れ、停電したときは「どうすれば？」に答えてから見なおす（ミッション2「火力ゼロ」だけは、停電することを見つける実験なので目標に入れない）
- **💸 建設費と燃料代**：シナリオの表で、建設費は「はじめに1回」、燃料代は「🔥を動かした分。建てなくても毎日かかる」と表示。「何もしない」でも🔥があれば燃料代はかかる

- 記録（音の設定・学習レポート）は、そのブラウザの中に保存されます
- URL の後ろに `?debug` を付けると、開発者ツールから `__ec.mirai()`（おまけを はじめる）・`__ec.mnext()`（3年すすめる）などが使えます（調整用）
- 元の町づくり（リアルタイムのステージ・フリープレイ・チュートリアル）のプログラムは main.js・stages.js・tutorial.js に残っているが、トップからは入れない
