# 資料フォルダ

ゲームの数値を公的な資料にそろえるために使います。

## 先生に入れてほしいPDF（2つ）

サイト側がプログラムからのダウンロードを拒否するため、ブラウザで開いて保存してください。保存先はこのフォルダ（game/資料）です。

1. **発電コスト検証ワーキンググループ 報告（2021年9月）**
   https://www.enecho.meti.go.jp/committee/council/basic_policy_subcommittee/mitoshi/cost_wg/pdf/cost_wg_20210908_01.pdf
   → 保存名：`発電コスト検証2021.pdf`
2. **発電コスト検証に関するとりまとめ（2025年2月）**
   https://www.enecho.meti.go.jp/committee/council/basic_policy_subcommittee/mitoshi/cost_wg/pdf/cost_wg_20250206_01.pdf
   → 保存名：`発電コスト検証2025.pdf`

この2つから、電源ごとの「建設費（万円/kW）」「設備利用率」「燃料費」「運転維持費」を読み取り、ゲームの🪙の建設費・燃料代・出力にそろえます。

## もう入っているもの

- `東京エリア需給実績2024/`：東京電力パワーグリッド「でんき予報 エリア需給実績」2024年1〜12月（30分ごと・MW）
  - 出典：https://www.tepco.co.jp/forecast/html/download-j.html
  - `集計.py` で、次の値を出しました（python で実行）
    - 猛暑の日の使う量：7月でいちばん多く使った日は、中央値の日の約1.16倍（1日の量）。最大需要では約1.20倍
    - 雨の日の太陽光：6月で少ない日（下から1割）は、多い日（上から1割）の約2割
    - 風の弱い日：1年で風力がいちばん少ない日は、中央値の日の約1割
    - 使う量の1日の形：夏は13〜14時、冬は9時と18時がいちばん多い
