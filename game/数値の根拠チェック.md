# エネルギーシティ　数値の根拠チェック（2026年10月31日）

ゲームの中の数値を1つずつ確かめ、根拠（出典）があるかを分けました。

- ✅ … 公的な資料に根拠がある（出典は js/facts.js）
- ⚠️ … 根拠の一部がある／本家「大作戦」や作者の考え方（意見）／出典をまだ確認していない
- ❌ … 根拠がない（作者がゲームのつり合いで決めた数）
