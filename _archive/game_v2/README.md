# エネルギーシティ（試作版 v2）

`index.html` をブラウザで開くだけで遊べます（フォントはGoogle Fontsから読み込みます）。

## ファイル構成
| ファイル | 中身 |
|---|---|
| `js/balance.js` | **調整用の数値はすべてここ**。電源・イベント・ステージ・セリフ・コンボ・実績・ランク条件 |
| `js/sim.js` | 1時間ごとの需給計算、原因メッセージ、コンボ判定（DOMなし・Nodeでテスト可） |
| `js/render.js` | アイソメトリック描画、キャラの表情、天気、夜の明かり、グラフ |
| `js/game.js` | ゲームの流れ、操作、画面（タイトル・ふりかえり・結果・図鑑・実績） |
| `style.css` | 見た目 |

## 遊びの柱
1. **その場で操作できる1日**：⚠ピンチ予報が出たら 📢節電／🔥火力フルパワー／🔒蓄電池を温存 で乗りきる
2. **予報で読み合い**：来年のイベントが確率つきで出る。備えるか、賭けるか
3. **電源キャラ**：ひなた☀️・ふうた🌬️・ほむら🔥・みずき💧・ゆげまる♨️・げんた⚛️・ためるん🔋。状況に応じた表情とセリフで特徴を伝える
4. **コンボ＆ミックスボーナス**：電源を組み合わせるほどスコアが伸びる
5. **ステージ・実績・今日のステージ**：はじまりの町／しまの町（川なし・燃料高）／ゆきの町（冬・朝夕ピーク）。日付シードで全員が同じイベントになる

## よく触る調整ポイント（`balance.js` の `EC.BALANCE`）
- 難しすぎる → `startMoney` を上げる、`income` を上げる、`growth` のしきい値を上げる（町の育ちがゆっくりになる）
- 火力が強すぎる → `thermalRamp` を下げる（夕方の急な需要増に追いつけなくなる）、`fuelPrice` を上げる
- 1プレイを短く → `yearsPerTurn` を上げる、`hourMs` を下げる
- ランクの条件 → `rank`
- イベントの出やすさ → `EC.EVENTS` の `w`

## 先生向けメモ
- 1プレイは約6〜8分（2年×13ターン）
- 結果画面に、技術の見方・考え方の4観点のレーダーチャートと、日本の電源構成（2023年度実績・2040年度見通し）との比較を表示します
- 「今日のステージ」は、その日の全員が同じステージ・同じイベント順で遊べます。結果画面のテキストをコピーして共有できます
- 記録（ベスト・実績）は端末のブラウザに保存されます
